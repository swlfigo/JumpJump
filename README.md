# JumpJump 跳一跳

**按住蓄力，松手起跳。找到节奏，再跳远一点。**

JumpJump 是一款适合随时玩上一局的 iPhone 休闲跳跃游戏。控制小棋子在错落的平台之间前进，根据距离掌握蓄力时机，瞄准中心、积累连击，挑战自己的最高纪录。

## 游戏特色

- **单手轻松玩**：按住与松开，两个动作就能完成一次跳跃。
- **简洁立体画面**：柔和配色搭配几何平台，让每一步落点都清晰直观。
- **中心连击奖励**：连续落在平台中心，收获逐次递增的加分。
- **生动的跳跃反馈**：翻转起跳、落地光环、加分飘字，配合音效与触觉反馈。
- **辅助练习模式**：用可视化力度提示练习蓄力，逐渐找到自己的手感。
- **局域网联机**：和同一 Wi-Fi 下的朋友同场竞速，从房间列表里加入，也可以开一个带密码的房间。
- **个人纪录挑战**：自动保存本机最高分，随时重开，再试一次。
- **声音自由切换**：通过底部开关选择是否播放游戏音效。

## 怎么玩

在首页点「单人游戏」开始；想和朋友比赛，见[局域网联机](#局域网联机)。

1. 在游戏区域的空白处按住屏幕，为小棋子蓄力。
2. 观察下一块平台的距离：平台越远，通常需要蓄力越久。
3. 松开手指，小棋子立即起跳。
4. 落在下一块平台上继续前进；尽量瞄准中心，争取连击。

短跳落回当前平台时，可以继续尝试。掉落后，点击「再来一局」重新挑战；也可以随时点击底部「重开」开始新的一局。

## 得分规则

飘出的数字就是当前这一跳获得的分数。

| 落点 | 本次得分 |
| --- | --- |
| 成功落在下一块平台的非中心区域 | +1 |
| 命中下一块平台的中心区域 | +2 |
| 连续第二次命中中心 | +4 |
| 连续第三次命中中心 | +6 |
| 继续保持中心连击 | 每次递增 2 分 |

一次普通落点会结束中心连击，下次命中中心重新从 +2 开始。落回当前平台不加分，也不会打断已有连击。

例如：**中心 → 中心 → 普通落点 → 中心**，依次获得 **+2、+4、+1、+2**。

## 辅助练习模式

想更直观地掌握蓄力时机，可以连续点击顶部得分 **10 次**开启辅助模式，再次连点 **10 次**关闭。点击时保持连贯，相邻两次间隔不要超过 3 秒。

开启后，屏幕底部会显示力度参考：

- **蓝色进度与圆点**：当前蓄力进度。
- **绿色区间**：建议松手的力度范围。
- **深色竖线**：瞄准下一块平台中心的理想力度。
- **数值提示**：目标力度、建议按压时长与当前力度。

提示会随当前站位和下一块平台更新，帮助你练习从判断距离到松手起跳的节奏。

辅助模式默认关闭。重开一局会保留当前选择，重新启动游戏后恢复关闭。

## 局域网联机

> 联机功能仍在探索阶段。

和同一 Wi-Fi 下的朋友同场竞速：所有人在同一串平台上同时开跑，互相看得见，比谁跳得更远。

### 先启动服务器

房间开在服务器上，所以要先在同一 Wi-Fi 下的一台电脑上运行 [JumpJumpServer](https://github.com/swlfigo/JumpJumpServer)（需要安装 Go）：

```sh
git clone https://github.com/swlfigo/JumpJumpServer.git
cd JumpJumpServer
go run ./cmd/jumpjump-server
```

服务器会在局域网里自动广播，手机不用填地址。第一次进入联机时，iPhone 会询问是否允许访问「本地网络」，请选择允许，否则找不到服务器。

一个人想先试试，可以再开一个终端运行 `go run ./cmd/jumpbot -name Bot`，房间列表里会多出一个机器人在等你的「Bot 的房间」。

### 进入房间

1. 在首页点「局域网联机」，游戏会自动连上找到的服务器，进入房间列表。
2. 填好昵称，然后：
   - **加入房间**：点列表里的房间。带锁图标的房间要输入房主设置的密码；对局中或已满的房间暂时不能进。
   - **创建房间**：想只让朋友进来，就先填一个房间密码，不填则所有人都能加入；再点「创建房间」。列表里会显示为「你的昵称 的房间」。
3. 进房间后点「准备」。房间里有 2–4 人且全员准备后，倒计时 3 秒开跑。

房间列表会实时刷新，点「离开房间」回到列表。如果一直没有发现服务器，可以手动输入服务器启动时打印的地址（如 `192.168.1.10:7788`），再点「连接服务器」。

> 房间密码只用来挡住不认识的人。局域网里是明文传输，请不要用自己的真实密码。

### 比赛规则

- 每位玩家有各自的颜色。你的棋子头顶有一个箭头，其他人是带名字的半透明棋子；左上角实时显示每个人的分数。
- 掉落后进入观战，所有人都出局后公布排名。正常掉落的玩家按分数排名。
- **挂机判负**：开跑后或上一跳后 60 秒没有起跳就判负出局，剩 15 秒时会提醒。
- **中途退出、断线**也算判负，暂不支持断线重连。判负的玩家排在所有正常掉落的玩家之后。
- **准备超时**：进房间后或一局结束后 15 秒内不准备，会被移出房间，最后 5 秒会倒计时提醒。
- 结算后点「再来一局」回到房间等其他人；如果房间里只剩你，会回到首页。
- 联机时辅助练习模式不可用。

## 支持设备

适用于运行 **iOS 18 及以上版本**的 iPhone。
